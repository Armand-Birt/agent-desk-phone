“Hey Siri, jot it down”

A Siri shortcut that saves what you say straight to the Notepad, without opening this page. In the Shortcuts app, make a new shortcut with these actions:
  1. Dictate Text (set its language; “Stop Listening: After Pause”).
  2. Get Contents of URL · Method POST · URL
    Headers: apikey =
    Request Body JSON: email = your email, password = your password.
  3. Get Dictionary Value · Get Value for access_token in Contents of URL.
  4. Get Contents of URL · Method POST · URL
    Headers: apikey = the same key; Authorization = Bearer followed by Dictionary Value.
    Request Body JSON: target_device = *, from_device = phone, from_name = Siri, item = notepad, kind = note, and result = a Dictionary with text = Dictated Text.
  5. Name the shortcut (e.g. “Jot it down”): that name is what you say to Siri.
Your password is stored in the shortcut on this phone.
